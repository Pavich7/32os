# 32os  

**An open-source serial command line interface operating system for ESP32 Series. Inspired by Linux.**

## ⭐ Features  

- **File System support**  
- **Linux shell-like interface**  
- **GPIO Supported**  
- **WiFi and time sync supported**  

## 🏗️ Building and Running  

### 📌 Requirements  

- **Arduino IDE** with Arduino-ESP32 installed  
- **PuTTY** for best serial console support  

### ⚙️ Building the Project  

```bash
git clone https://github.com/Pavich7/32os.git
```
- Open the `.ino` file in **Arduino IDE**  
- Select your **ESP32 board type** and **port**  
- Hit **Upload**  
- Done! 🎉

### ▶️ Running  

You can use any serial console with this project, but **PuTTY** is recommended for the best support.  
The default baud rate is `115200`
