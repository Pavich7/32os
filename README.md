# 32os

**An open-source serial command line interface operating system for ESP32 Series. Inspired from Linux.**

## ⭐ Features  

* ✅ **File System support**
* 🌐 **Linux shell like interface**
* 🎮 **GPIO Supported**
* 🚀 **WiFi and time sync supported**

## 🏗️ Building and Installing

### 📌 Requirements  

* 🖥️ **Arduino IDE** with Arduino-ESP32 installed.
* 🖥️ **PuTTY** for best serial console supported.

### ⚙️ Building the Project  

git clone https://github.com/Pavich7/32os.git
Open .ino file on Arduino IDE
Select your ESP32 board type and port and hit upload.
Done!
